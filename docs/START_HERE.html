📖 How to use this guide

  • Go in order. Do the parts in number order, and inside a part do one step at a time.
  • Tick each step when it's finished. Click its Done box. Your ticks are saved in this browser, so you can close the page and come back later. ▶ Jump to my next step takes you to the first step you haven't ticked yet.
  • Blue boxes (👀 You should see) show what the screen should look like when a step works.
  • Red boxes (🆘 If it goes wrong) say how to fix it. Click one to open it.

Set up your laptop

⏱️ 60–90 min💻 laptop📅 today · to-do card #1

You'll install 4 free programs, download the project, run a check-up program called doctor, and send its report to Kiro. Plug in your charger and use Wi-Fi: the downloads add up to about 1 GB.

💻 Your laptop (from your screenshot)

Lenovo IdeaPad 5 15IIL05 · Windows 11 Home · Intel Core i7-1065G7 · 16 GB RAM · Intel Iris Plus Graphics (built in) · about 159 GB free.

✅ Good enough for Blender 5.2. Blender supports Intel's built-in graphics from 7th-gen chips onwards, and yours is 10th-gen. The "128 MB" next to Graphics Card is normal: built-in graphics borrow memory from your 16 GB. Final renders will be slow, so you'll run them overnight (Part 9). Your keyboard has a number pad, which Blender uses to switch views. A mouse with a scroll wheel (₹300–₹800) makes Blender much easier.

  1. (Recommended) Update Windows and the graphics driver

    1. Press the ⊞ Windows key, type Windows Update and press Enter.
    2. Click Check for updates, install everything, and restart if it asks.
    3. Back on Windows Update, click Advanced options, then Optional updates. If there's a Driver updates list, tick anything from Intel that mentions Display or Graphics, then click Download & install.

    Why: Blender needs an up-to-date graphics driver. This can take 10–30 minutes, so start it now and come back.

  2. Open the Terminal

    Press the ⊞ Windows key, type Terminal and press Enter.

    A dark window with a line like PS C:\Users\yourname> and a blinking cursor. This is where commands go.
    How every command works
    1. Click Copy next to the command in this guide.
    2. Click inside the Terminal window, then press Ctrl+V (or right-click) to paste.
    3. Press Enter.
    4. Wait until the PS C:\...> line comes back before you paste the next command.
    Never type the PS C:\...> part yourself. It's just the Terminal saying "ready".
    🆘 If it goes wrong
    • No "Terminal" app: type PowerShell instead and open Windows PowerShell. It works the same way.
    • Ctrl+V shows ^V: right-click to paste instead.

  3. Install Git (downloads the project and its updates)

    winget install --id Git.Git -e --accept-source-agreements --accept-package-agreements

    If a window asks "Do you want to allow this app to make changes to your device?", click Yes. Do the same in the next steps too.

    After 1–3 minutes, the words Successfully installed.

  4. Install Python 3.13 (runs Kiro's scripts)

    winget install --id Python.Python.3.13 -e --accept-source-agreements --accept-package-agreements
    Successfully installed

    Why 3.13 and not the newest version: every add-on package the project needs is ready for it, and Blender 5.2 uses 3.13 inside too.

  5. Install FFmpeg (turns pictures and sounds into videos)

    Successfully installed. It may also say "Path environment variable modified; restart your shell". That's normal, and step 3.7 takes care of it.

  6. Install Blender 5.2 LTS (the 3D animation program)

    winget install --id BlenderFoundation.Blender -e --version 5.2.2 --accept-source-agreements --accept-package-agreements

    It's a big download (about 400 MB), so it takes 3–10 minutes. Click Yes if Windows asks for permission.

    Successfully installed

    3. Open the downloaded file and click Next, then tick to accept, then Next, Next, Install, Yes, Finish. Don't change the install folder.

    • "git" or "ffmpeg" is not recognized: restart the laptop and try again. If ffmpeg still fails, see If something goes wrong.
