# The first 12 episodes

One new gag each. All 8 pillars appear by E011. Saturdays from the target launch of 14 Nov 2026
(decision 005). Each storyboard follows the guide's six boxes (§16.1): hook → setup → twist →
payoff → loop bridge, plus the key expression. Lengths are 6–10 s. Motions marked * don't exist
yet; Phases 3–4 build them.
