# Decisions

Each file records one decision: what was decided, why, and what it costs. Numbering:
`000` covers repo and tooling conventions; `001` onwards are the creative decisions from Phase 1
(name, character, sidekick, world, strategy, voice).

## How to veto

You don't need to explain much. Either comment `veto: <one line why>` on the PR that added the
decision, or open an issue titled `Veto: <decision>`. Kiro then makes a new decision, records why
the old one was replaced, and updates everything that depended on it.
