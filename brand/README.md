# Brand data (machine-readable)

This folder is the single source of truth for the character. The scripts read it, so the 3D
model, the character sheets and the captions always match.

- `character.json`: the character bible (Phase 1)
- `palette.json`: brand colours as hex (Phase 1)
- `emotions.json`: the emotion library (Phase 3)

The human-readable brand bible lives in `docs/brand/`.
