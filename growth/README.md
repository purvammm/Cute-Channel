# Growth data

These are plain CSV files, so you can open them in Google Sheets.

- `idea_bank.csv`: every episode idea, scored (Phase 1 seeds it; Phase 8 adds to it)
- `calendar.csv`: what to post when, including festival dates (Phase 1/8)
- `teardown.csv`: notes from studying other accounts (guide §1 template, Phase 8)
- `weekly_stats.csv`: per-Reel metrics (Phase 10)

The client prospect list (Phase 11) will not live here while the repo is public (see `docs/HUMAN_TASKS.md`).
